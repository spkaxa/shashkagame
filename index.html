📜 Правила русских шашек

  • Игра на тёмных полях доски 8×8, по 12 шашек.
  • Простая шашка ходит по диагонали вперёд на одну клетку.
  • Дамка ходит по диагонали на любое свободное поле вперёд и назад.
  • Взятие обязательно. Если есть возможность бить — нужно бить. Если можно побить несколько — бейте цепочкой.
  • Простая шашка бьёт вперёд и назад, дамка — по любым диагоналям.
  • При достижении последнего ряда простая шашка становится дамкой.
  • Победа: у соперника нет шашек / нет ходов / просрочено время / сдача.
  • Ничья: 20 минут игры / повторение позиции 3 раза / 3 дамки против 1.
